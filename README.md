# Personal Profile Card

A simple and clean personal profile card built using **HTML** and **CSS**.  
This project displays a profile image, name, role, and location in a modern card layout.

---

## 🚀 Features
- Responsive profile card design
- Clean and minimal UI
- Built with pure HTML & CSS
- Easy to customize

---

## 🛠️ Technologies Used
- HTML5
- CSS3
